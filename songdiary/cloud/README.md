# 노래일기 계정·동기화 준비 (Supabase, 한 번만)

로그인하면 같은 이메일로 로그인한 기기끼리 기록과 녹음이 맞춰져요.
기록은 **내 Supabase 프로젝트**에만 저장되고, 로그인한 본인 계정만 읽고 쓸 수 있어요 (setup.sql의 규칙).

> **지금 상태 (2026-09-27)**: 앱에는 이미 내 프로젝트(**ggumtak's Project**, 서울)가 들어 있고, `setup.sql`도 적용해 두었어요.
> 그래서 1·2·4번은 끝났고, 남은 건 **3번(로그인 메일에 번호 넣기)** 과 나중에 **5번(가입 막기)** 뿐이에요.
> 아래 1·2·4번은 다른 프로젝트를 새로 쓸 때를 위한 설명이에요.

## 1. 프로젝트 만들기 (5분)

1. <https://supabase.com> → **Start your project** → GitHub나 Google 계정으로 가입
2. **New project**
   - Name: `songdiary` (아무 이름이나)
   - Database Password: 아무거나 (따로 적어 두기만 하세요. 앱에는 필요 없어요)
   - Region: **Northeast Asia (Seoul)**
   - Plan: Free
3. 1~2분 기다리면 프로젝트가 준비돼요.

## 2. 표 만들기

1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. 이 폴더의 [`setup.sql`](setup.sql) 내용을 **전부** 복사해서 붙여 넣고 **Run**
3. 아래에 `Success. No rows returned`가 나오면 끝이에요. (다시 실행해도 괜찮아요.)

## 3. 로그인 메일에 번호 넣기

앱은 메일로 받은 **번호**(보통 6자리)로 로그인해요.

1. **Authentication** → **Emails** (또는 Email Templates)
2. **Magic link** 템플릿의 본문(Body)을 이렇게 바꾸고 저장
   ```html
   <h2>노래일기 로그인</h2>
   <p>앱에 이 번호를 넣어 주세요: <b>{{ .Token }}</b></p>
   ```
3. **Confirm signup** 템플릿도 같은 내용으로 바꾸고 저장 (처음 로그인할 때는 이 메일이 가요)

> ⚠️ Supabase의 기본 메일은 **Supabase 계정의 이메일**(조직 팀원 이메일)로만 가고, **한 시간에 2통**까지예요.
> 그래서 앱에서도 **Supabase에 가입한 그 이메일**로 로그인하는 게 가장 쉬워요.
> 다른 이메일(가족 등)로도 로그인하려면 **Organization → Team**에 그 이메일을 초대하거나,
> **Authentication → Emails → SMTP Settings**에 내 메일 서버(Gmail 앱 비밀번호 등)를 넣어 주세요.

## 4. 앱에 연결하기

1. **Project Settings** → **API** (또는 **Data API** / **API Keys**)에서 두 값을 복사
   - **Project URL**: `https://xxxxxxxx.supabase.co`
   - **anon public** 키 (또는 **publishable** 키: `sb_publishable_…`)
   - ⚠️ `service_role` / `secret` 키는 절대 넣지 마세요. 그 키는 모든 걸 열 수 있어요.
2. 앱: **설정 → 계정·동기화 → 서버 연결하기**에 붙여 넣고 **연결하기**
3. **이메일로 로그인** → 메일로 온 6자리 번호 입력
4. 다른 폰·태블릿에서도 1번부터 같은 이메일로 로그인하면 기록이 맞춰져요.

## 5. 가입 막기 (모든 기기에서 한 번씩 로그인한 뒤)

앱 안의 키는 공개용이라, 누구든 그 키로 **새 계정**을 만들 수는 있어요 (내 기록은 못 봐요).
모르는 사람이 무료 용량을 쓰지 못하게, 쓸 기기에서 모두 한 번씩 로그인한 뒤에는 가입을 막아 두세요.

- **Authentication → Sign In / Providers** (또는 Providers → Email) → **Allow new users to sign up** 끄기 → 저장
- 이미 로그인했던 이메일은 계속 번호로 로그인할 수 있어요. 새 이메일을 쓰려면 잠깐 다시 켜면 돼요.

> 두 값을 저(Claude)에게 보내 주시면 앱 안에 넣어서 업데이트로 보내 드릴 수 있어요.
> 그러면 기기마다 연결할 필요 없이 로그인만 하면 돼요. anon/publishable 키는 앱에 들어가도 되는 공개용 키예요.

## 어떻게 맞춰지나요

- 앱을 열 때, 다시 돌아올 때, 적고 몇 초 뒤, 5분마다 서버와 맞춰요. 인터넷이 없으면 폰에 저장해 두었다가 연결되면 보내요.
- 두 기기에서 **같은 날**을 동시에 고치면 둘 다 합쳐요 (적은 내용이 사라지지 않게).
- 녹음은 설정에서 끌 수 있고, 기본은 **Wi-Fi에서만** 주고받아요. 다른 기기에서 만든 녹음은 재생할 때 받아 와요.
- 처음 로그인한 폰에 이미 기록이 있으면, 서버의 기록과 합쳐요.
- **자동 로그인**: 폰마다 한 번만 로그인하면 돼요. 앱을 껐다 켜도, 앱이 업데이트돼도, 며칠 안 써도 로그인은 그대로예요.
  로그인이 풀리는 건 직접 **로그아웃**했을 때, 앱을 지웠을 때, Supabase에서 그 로그인을 끊었을 때뿐이에요.
  인터넷이 끊기거나 서버가 잠깐 바빠도 로그인은 풀리지 않고, 나중에 다시 맞춰요.
- 다시 로그인할 때는 지난번 이메일이 미리 적혀 있어요.
- 로그아웃해도 폰의 기록은 그대로예요.
- **폰을 잃어버렸다면**: 다른 기기에서 설정 → 계정·동기화 → **다른 기기 로그아웃**. 그 폰은 다음에 로그인을 갱신할 때
  (늦어도 1시간 안에) 로그인이 풀려요. 더 빨리 끊기게 하려면 Supabase 설정에서 JWT(Access token) 만료 시간을 줄이면 돼요.
- 녹음을 지우면 서버에서도 **하루 뒤에** 지워져요 (다른 기기가 따라오는 동안 잠깐 비는 걸 지우지 않게).

## 무료 플랜에서 알아 둘 것

| | 무료 |
|---|---|
| 글 기록 (데이터베이스) | 500MB — 몇십 년 써도 충분해요 |
| 녹음 (파일 저장) | 모두 합쳐 1GB, 한 파일 50MB까지 (넘는 녹음은 올리지 않고 폰에만 둬요) |
| 로그인 메일 | 기본 메일은 Supabase 계정(팀원) 이메일로만, 한 시간에 2통까지 (3번 참고) |
| 쉬는 프로젝트 | 1주일 넘게 아무도 쓰지 않으면 프로젝트가 잠시 멈춰요. Supabase 사이트에서 **Restore**를 누르면 다시 켜져요. |

## 문제가 생기면

- "서버에 아직 표가 없어요" → 2번(setup.sql)을 실행하지 않았어요.
- 번호 메일이 안 와요 → 스팸함 확인, 3번 템플릿에 `{{ .Token }}`이 있는지 확인, 한 시간쯤 뒤 다시.
- "이 이메일로는 번호를 보낼 수 없어요" → 3번의 ⚠️: Supabase 계정 이메일로 로그인하거나 팀원 초대·SMTP 설정.
- "새 가입을 막아 두었어요" → 5번에서 가입을 막아 둔 상태예요. 전에 쓰던 이메일로 로그인하거나 잠깐 다시 켜세요.
- "키가 맞지 않아요" → anon(public)/publishable 키인지 확인.
